# Implement Frontend View

**Skill Description:** Builds frontend components following state management and layout guidelines.

## Instructions
1. Scaffold views using React + Tailwind CSS.
2. Ensure components are modular and placed in `src/frontend/src/components/` if reusable.
3. Construct full pages in `src/frontend/src/views/`.
4. Use React Query for all server-state data fetching (no raw `useEffect`).
5. Use Zustand for local client-side state.
6. Lazy-load heavy views (e.g., EMR history, reports) using `React.lazy`.
7. Coordinate with `@uiux-agent` to ensure all tap targets are ≥ 44x44px.
