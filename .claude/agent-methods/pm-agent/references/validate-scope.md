# Validate Scope

**Skill Description:** Checks if a feature request aligns with the current roadmap phase.

## Instructions
1. Analyze the requested feature.
2. Read the current phase from `.claude/roadmap/`.
3. If the feature is not explicitly listed in the current phase or MVP plan, FLAG IT as scope creep.
4. Propose deferring the feature to a later phase (e.g., "Add to Phase 3 Backlog").
5. Only approve features that are critical for the current development phase.
