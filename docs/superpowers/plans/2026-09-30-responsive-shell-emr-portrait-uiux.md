# RESP-6a — EMR portrait design note (UIUX A)

Applies when `tabbed = useViewportMode() === 'drawer'` (768 portrait). Every class swap is conditional on `tabbed` (class / `hidden` only; panels keep element type and tree position, so no remount). 1024/1280 keeps today's three columns. Tokens only; icons via `MaterialIcon` (Material Symbols); no emoji, no raw hex, no `lg:`/`xl:` as the mode switch.
