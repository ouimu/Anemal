# แบบออกแบบ: คู่มือการใช้งาน Anemal สำหรับผู้ใช้คลินิก

## เป้าหมาย

จัดทำคู่มือภาษาไทยแบบละเอียดสำหรับผู้ที่เริ่มใช้ระบบ Anemal โดยครอบคลุมผู้ใช้ใน Clinic plane สามบทบาท ได้แก่ Staff, Doctor และ Clinic Admin เท่านั้น ผู้อ่านต้องสามารถทำงานตามคู่มือได้ทีละขั้นโดยไม่ต้องมีพื้นฐานการใช้ระบบมาก่อน

## ขอบเขต

รวม:

- การเข้าสู่ระบบ การเลือกสาขา การใช้งานเมนู และการตั้งค่าส่วนบุคคล
- งานของ Staff และ Doctor: Dashboard, นัดหมาย, เจ้าของและสัตว์เลี้ยง, EMR, ใบสั่งยา, วัคซีน, ผู้ป่วยใน, คลังเลือด, คลังสินค้า/โอนสินค้า, Billing/POS, ประวัติการชำระเงิน และ Grooming
- งานของ Clinic Admin: Dashboard, ผู้ใช้, รีเซ็ตรหัสผ่านพนักงาน, บทบาทและสิทธิ์, สาขา, การตั้งค่าคลินิก, เวลาเปิดทำการ, การแจ้งเตือน, การชำระเงิน, การเชื่อมต่อ, การใช้ระบบ, การสมัครใช้บริการ และบันทึกกิจกรรม
- คำถามที่พบบ่อย ข้อควรระวัง และตารางสิทธิ์การใช้งาน

ไม่รวม:

- ทุกหน้าจอและทุกขั้นตอนภายใต้ `/platform/*` รวมถึง Platform Admin, Customers, Plans, Platform Settings และ Platform Audit
- ฟีเจอร์ที่ยังไม่พร้อมใช้งานจริง เช่น การเชื่อม payment gateway และการส่ง LINE/SMS จริง โดยจะอธิบายเฉพาะสิ่งที่ผู้ใช้มองเห็นในหน้าจอเมื่อเกี่ยวข้อง

## รูปแบบคู่มือที่เลือก

ใช้คู่มือฉบับรวมตามเมนู (master manual) พร้อมป้ายบทบาทในแต่ละหัวข้อ แทนการทำคู่มือสามเล่มแยกกัน เพื่อให้ผู้ใช้ค้นหางานได้จากเมนูเดียว และลดเนื้อหาซ้ำระหว่างบทบาท

โครงเล่ม:

1. ปก คำอธิบายเอกสาร และสารบัญ
2. เริ่มต้นใช้งาน: เข้าใช้ระบบ เลือกสาขา เมนูหลัก ภาษา และรหัสผ่าน
3. บทบาทและสิทธิ์ของ Staff, Doctor และ Clinic Admin
4. งานหน้าคลินิก: Dashboard, นัดหมาย, เจ้าของและสัตว์เลี้ยง
5. งานรักษา: EMR, ใบสั่งยา, วัคซีน, ผู้ป่วยใน และคลังเลือด
6. งานปฏิบัติการและการขาย: คลังสินค้า/โอนสินค้า, Billing/POS, ประวัติการชำระเงิน และ Grooming
7. การดูแลระบบคลินิก: ผู้ใช้ รหัสผ่าน บทบาท สาขา การตั้งค่า และบันทึกกิจกรรม
8. คำถามที่พบบ่อยและวิธีแก้ปัญหาเบื้องต้น
9. ภาคผนวก: คำศัพท์และตารางสิทธิ์

## มาตรฐานเนื้อหา

- ทุกงานใช้คำสั่งสั้น ชัดเจน และเรียงลำดับเป็นขั้นตอน
- ทุกรูปหน้าจอมีหมายเลขภาพ คำบรรยาย และกรอบ/หมายเลขกำกับตำแหน่งที่ต้องกด
- แต่ละหัวข้อระบุ `ใช้ได้โดย` เพื่อบอกบทบาทที่มีสิทธิ์ และระบุชัดเจนเมื่อสิทธิ์จริงอาจต่างตามการตั้งค่าของคลินิก
- ใช้ตัวอย่างข้อมูลที่ไม่ใช่ข้อมูลผู้ป่วยจริง และไม่ใส่รหัสผ่านหรือข้อมูลลับในรูป
- ใช้คำศัพท์สม่ำเสมอ: เจ้าของสัตว์เลี้ยง, สัตว์เลี้ยง, เวชระเบียน (EMR), ใบแจ้งหนี้, ผู้ป่วยใน และ Clinic Admin

## ภาพประกอบ

ใช้ภาพจากหน้าจอแอปจริงในสภาพแวดล้อมทดสอบที่มีข้อมูลตัวอย่างเป็นแหล่งหลัก ภาพจะครอบคลุมหน้าและหน้าต่างสำคัญของทุกโมดูลในขอบเขต ไม่ใช้ภาพตัวอย่างใน `design_prototype` แทนหน้าจอจริงหากหน้าจอจริงพร้อมใช้งาน

## งานออกแบบเอกสาร

- ขนาดกระดาษ A4 แนวตั้ง เป็น named override สำหรับคู่มือภาษาไทย
- ปกแบบ editorial cover ที่เรียบสะอาด และส่วนเนื้อหาใช้หัวกระดาษ/เลขหน้าแบบเงียบ
- ใช้ฟอนต์ `Leelawadee UI` ทั้งข้อความไทยและอังกฤษ เพื่อให้รูปเล่มร่วมสมัย อ่านง่าย และมีในระบบที่ใช้สร้างไฟล์
- ใช้สีน้ำเงินเข้มและเขียวอมฟ้าเป็นสีเน้น จำกัดการใช้สีไว้ที่ลำดับชั้น หัวข้อ ป้ายบทบาท และกล่องข้อควรระวัง
- ใช้ Heading 1-3, รายการเลขลำดับ และตารางสิทธิ์ที่เป็น Word styles/numbering จริง เพื่อให้สารบัญและการส่งต่อเป็น PDF ใช้งานได้ถูกต้อง

## ผลลัพธ์

- `docs/Anemal-คู่มือการใช้งาน-Clinic-Users-TH.docx` เป็นไฟล์ Word ต้นฉบับ
- ไฟล์ PDF ที่เรนเดอร์จาก Word เพื่อใช้ตรวจคุณภาพและส่งให้ใช้ได้ทันที

## เกณฑ์ยอมรับ

- ไม่ปรากฏเนื้อหา Platform Admin ในคู่มือ
- ครอบคลุมเมนู Clinic และ Clinic Admin ที่อยู่ในเส้นทางปัจจุบันของแอป
- ภาษาไทยถูกต้อง อ่านลื่น และไม่มีอักขระผิดรูปหรือการเข้ารหัสผิด
- ทุกหน้าในไฟล์ Word ถูกเรนเดอร์เป็น PNG/PDF และตรวจด้วยตาแล้ว: ตัวอักษรไม่หาย, ภาษาไทยไม่แสดงเป็นภาษาประหลาด, ภาพไม่ทับข้อความ, ตารางไม่ตัด และหัว/ท้ายกระดาษไม่ผิดตำแหน่ง
- ตรวจทานข้อความอย่างน้อยสองรอบ: ความถูกต้องตามหน้าจอ/สิทธิ์ และการพิสูจน์อักษรภาษาไทย
